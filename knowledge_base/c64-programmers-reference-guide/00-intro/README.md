# Commodore 64 Programmer's Reference Guide

## Overview

Il **COMMODORE 64/EXECUTIVE 64 PROGRAMMER'S REFERENCE GUIDE** è stato sviluppato come strumento di lavoro e fonte di riferimento per chi desidera massimizzare l'uso delle capacità integrate del COMMODORE 64 e EXECUTIVE 64.

Questo manuale contiene le informazioni necessarie per i programmi, dal più semplice esempio fino al più complesso.

## A chi è destinato

- Programmatori BASIC principianti
- Programmatori professionisti esperti in linguaggio macchina 6502
- Chiunque voglia sfruttare appieno le capacità del Commodore 64

## Contenuti principali

1. **BASIC Programming Rules** - Regole fondamentali della programmazione BASIC
2. **BASIC Language Vocabulary** - Vocabolario completo del linguaggio BASIC
3. **Programming Graphics** - Grafica, sprite e modalità video
4. **Programming Sound and Music** - Suono, musica e sintetizzatore SID
5. **BASIC to Machine Language** - Dal BASIC al linguaggio macchina 6502
6. **Input/Output Guide** - Guida completa alle periferiche e porte

## Caratteristiche tecniche del C64

- Processore: MOS Technology 6510
- RAM: 64 KB
- ROM: 20 KB (BASIC, KERNAL, Character Set)
- Chip grafico: VIC-II (6566/6567)
- Chip audio: SID (6581)
- Chip I/O: CIA (6526) x2
- Risoluzione: fino a 320x200 pixel
- Colori: 16 colori
- Sprite: 8 sprite hardware
- Voci audio: 3 voci indipendenti
